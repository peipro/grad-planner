# 🎓 研途计划 · 使用指南

> 研究生计划与日程管理桌面工具 —— 日历 / 待办 / 里程碑 / 笔记 / 番茄钟 / 习惯 / 生日 / 文献阅读 / 统计 / 资讯 / 翻译，一站式管理你的研究生涯。
>
> Electron + React + TypeScript 开发，数据完全保存在本地，无需注册账号，支持桌面与平板局域网共享。

---

## 📥 一、安装与启动

### 方式一：使用打包版（推荐）
- 免安装版：直接运行 `研途计划.exe`（绿色便携，软件放哪、数据就在哪）
- 安装版：`研途计划 Setup 0.2.0.exe`，可安装到任意目录并创建桌面快捷方式

### 方式二：从源码运行
```bash
npm install
npm run dev          # 浏览器调试
npm run desktop      # 桌面模式（需先 npm run build）
npm run deploy:desktop  # 构建并部署到 D:\研途计划（要求应用已关闭）
npm run dist         # 打完整安装包
```

### 首次使用建议
1. 打开「设置」→ 选择喜欢的主题与主题色
2. 打开「设置」→ 开启系统提醒与自动备份
3. 在「里程碑」里建好你的阶段节点（开题 / 中期 / 预答辩 / 答辩），系统会自动倒计时

## 📖 三、各模块使用说明

### 📅 日历
- **三种视图**：月 / 周 / 日，右上角切换
- **新建日程**：右上角「新建日程」，或双击日历空白格、双击时间槽
- **四种类型**：课程（蓝）/ 组会（紫）/ 截止（红）/ 生活（绿）
- **联动显示**：
  - 📌 待办到期日自动显示（点击跳转到待办页）
  - 🏁 里程碑结束日自动显示（点击跳转到里程碑页）
  - 🎂 生日自动显示（粉色，点击跳转到生日页）
- **悬停**：当日条目超过 3 条时，悬停查看全部

### ✅ 待办
- **自然语言快速添加**：`明天交报告`、`紧急 读完第三章`、`下周三组会`、`3天后交稿`、`高优先级 改论文`
- **三种视图**：列表（筛选）/ 看板（拖动卡片切换状态）/ 四象限（重要×紧急）
- **项目**：右上角「项目」创建（名称+颜色），任务按项目分组筛选
- **子任务**：任务卡片内「添加子任务」，逐项勾选
- **智能筛选**：今天 / 已逾期 / 本周 / 待办 / 进行中 / 已完成
- **逾期高亮**：过期未完成显示红色「⚠ 已逾期 N 天」
- **删除可撤销**：误删后右下角提示条可一键撤销

### 🗓️ 里程碑
- **创建**：名称 + 描述 + 关联项目 + 起止日期 + 颜色
- **倒计时**：卡片上实时显示「⏳ 剩余 X 天」，逾期显示「⚠ 已逾期 X 天」
- **检查点**：展开卡片「添加检查点」（如"完成文献综述"），逐个勾选
- **自动进度**：进度 = 检查点完成率 + 关联项目未完成任务（进行中记 0.5）

### 📝 笔记
- 左侧列表 + 右侧编辑器，支持 **Markdown** 语法与实时预览
- **标签**：新建时逗号分隔（如：`文献, 组会`），点击标签筛选
- **搜索**：标题 + 内容全文搜索
- **联动入口**：资讯页「存笔记」、翻译页「存笔记」都能一键把内容存进来

### 📚 文献阅读
- **分阶段管理**：阶段 0 基础架构 → 阶段 1 一般攻击 → 阶段 2/3 推荐攻击（阶段可自由增删）
- **导入**：下载 JSON 模板 → 让 AI 按模板生成阅读计划 → 导入（重复标题自动跳过）
- **进度管理**：未读 / 在读 / 已读 三态，统计完成率
- **转待办/转日历**：选中文献一键生成「[文献] xxx」待办或日程，自动关联阅读进度
- **同步**：修改计划日期即时保存，重复同步自动更新不重复创建

### 🍅 番茄钟
- **倒计时**：15/25/45/60 分钟，专注 → 休息自动循环，完成自动记录并发系统通知
- **正计时**：秒表模式，手动保存记录
- **关联任务**：输入框下拉选择待办，完成的番茄计入该任务
- **跨页面运行**：切到其他页面计时继续，窗口标题实时显示剩余时间
- 记录可单条删除或全部清空

### 🔥 习惯打卡
- **新建**：名称 + emoji + 每周目标次数（1-14 次）
- **打卡**：点「打卡」按钮或周条上的日期格子（支持补打卡/取消）
- 显示本周完成率与连续打卡天数

### 🎂 生日
- **添加**：名字 + 农历/阳历 + 月/日 + emoji + 备注
- **农历闰月**：勾选「闰月生日」，当年无闰月时自动按平月计算
- **倒计时**：顶部展示最近 6 个即将到来的生日，7 天内高亮
- **每年自动更新**：农历生日每年对应的公历日期自动换算

### 📊 统计
- 任务总数/完成率、总专注时长、今日习惯打卡
- **年度热力图**：每天一格，颜色深浅 = 番茄数 + 习惯打卡数
- 近 7 天专注柱状图、任务状态饼图、按任务专注汇总

### 📰 资讯
- 每日 09:00 / 15:00 自动抓取（可手动刷新），来源包括量子位、InfoQ、OpenAI、DeepMind、Hugging Face、TechCrunch 等
- **筛选**：全部 / AI 相关 / Agent / 官方发布
- **翻译**：英文卡片一键翻译，点击卡片阅读全文，可跳浏览器打开原文
- **联动**：卡片悬停出现「存待办」「存笔记」，把资讯变成学习任务

### 🌐 翻译
- 整段中英互译（自动识别语种），支持超长文本（自动按句子分段）
- **历史记录**：最近 20 条，点击可回填
- **存笔记**：译文可一键存为笔记（双语对照，自动打「翻译」标签）
- **置顶小窗**：`Ctrl+Shift+T` 随时呼出，自动读取剪贴板

### 🔍 全局搜索 / 快速记录
- `Ctrl+K` / `Ctrl+F`：跨模块搜索任务、日程、笔记、文献、里程碑、生日、习惯
- `Ctrl+Shift+K`：全局快捷键（应用未聚焦时也可用）呼出快速记录，自然语言输入自动识别为待办/日程/文献/里程碑

## 💾 五、数据、备份与恢复

### 数据保存位置（便携模式：软件放哪，数据就在哪）

| 项目 | 位置 |
|---|---|
| 主数据 | `软件目录\data\sync\grad-planner-storage.json` |
| 自动备份 | `软件目录\data\backups\backup-YYYY-MM-DD.json`（保留最近 14 天） |
| 局域网令牌 | `软件目录\data\lan-token.txt` |
| 提醒记录 | localStorage `grad-planner-reminders-sent`（保留 30 天） |

### 备份与恢复
- **自动备份**：设置页开启后每 10 分钟写一份磁盘备份（同一天覆盖）
- **手动导出**：设置页「导出备份」下载完整 JSON；「导入备份」恢复
- **一键恢复**：设置页备份列表点「恢复」（恢复前会提示覆盖确认）
- **清空数据**：清空前会**自动备份一次**，可从备份列表找回

> ⚠️ 数据完全本地保存；便携模式下删除软件目录会连带删除数据，建议定期「导出备份」到网盘。

## 📱 六、局域网共享（桌面 ↔ 平板/手机）

研究生主力场景：**桌面端记计划，平板/手机随时看**。同一 WiFi 下：

1. 桌面版启动后自动开启局域网服务（端口 8899）
2. 打开「设置」→「局域网共享」卡片，看到访问地址（形如 `http://192.168.x.x:8899/?token=…`）
3. 平板/手机浏览器（同一 WiFi）打开该地址，即可使用完整功能并与桌面端共享同一份数据
4. 任一端修改，另一端自动刷新（约 1 秒内生效）
5. 安全：数据接口需携带令牌；「重置令牌」可让所有已连接设备立即失效

> 提示：地址中的 token 请勿外传；平板端修改后桌面端会自动刷新页面。

## ❓ 七、常见问题

**Q：资讯 / 翻译提示连接超时？**
这两项依赖网络代理（如 Clash）。应用会自动探测常见代理端口（7897/7890 等），若仍失败请确认代理节点可用。

**Q：X（推特）来源怎么开启？**
设置页填写 X API 的 Key + Secret（需有 API 读取额度），密钥经系统安全存储加密保存，不会明文写入配置。

**Q：提醒不响？**
首次使用请在系统设置中允许「研途计划」发送通知；提醒在设置页可分别调日历提前分钟数与生日提前天数。

**Q：清空数据能找回吗？**
清空前会自动备份到 `data\backups\`，可从设置页备份列表恢复。

**Q：为什么桌面端会自动刷新页面？**
平板端修改数据后，桌面端自动刷新以加载最新数据（这是局域网同步机制，属正常现象）。

**Q：如何更新软件？**
替换 `研途计划.exe` 与 `resources\` 即可；`data\` 目录保留即数据不丢。源码更新则 `npm run build` + `npm run deploy:desktop`。

## 🛠️ 八、开发者指南

> 📁 源码工程位置：`D:\研途计划\planner-app`（与打包版同目录；`D:\研途计划` 根目录是运行版 + `data\` 数据目录，两者互不干扰）。

### 技术栈
Electron 43 · React 18 · TypeScript 5 · Zustand · Vite 5 · date-fns · recharts · marked · lunar-javascript

### 常用命令
```bash
cd /d D:\研途计划\planner-app
npm run dev            # 浏览器调试（vite）
npm run build          # 类型检查 + 构建 dist
npm run test           # vitest 单测
node --test electron/lan-server.test.cjs   # 局域网服务测试
npm run deploy:desktop # 构建 + 打包 + 部署到 D:\研途计划（需先关闭应用）
npm run dist           # 生成安装包
```

### 项目结构
```
planner-app/
├── electron/          # 主进程：窗口、快捷键、备份、资讯抓取、翻译、局域网服务
│   ├── main.cjs       #   入口（含写入节流、原子写、同步刷新守卫）
│   ├── lan-server.cjs #   局域网 HTTP 服务（纯 Node，可独立测试）
│   ├── news.cjs       #   RSS/热搜/X API 抓取 + 翻译
│   └── preload.js     #   渲染进程安全桥接
├── public/sync-adapter.js  # localStorage → 共享文件 同步适配层（平板 PUT 节流）
├── src/
│   ├── App.tsx        # 主界面（导航 + 全局计时器/提醒器）
│   ├── store.ts       # Zustand 全局状态（持久化）
│   ├── types.ts       # 类型定义
│   ├── lib/           # 自然语言解析、农历、番茄钟、提醒、导入
│   ├── views/         # 12 个功能页面
│   ├── components/    # 全局搜索、快速记录、弹窗、Toast 等
│   └── styles/        # 全局样式（浅/深色主题变量）
├── scripts/deploy.cjs # 构建部署脚本
└── release/           # 打包产物（win-unpacked / 安装包）
```

### 架构要点
- **单份数据源**：所有模块状态存于 Zustand store，持久化到 `data\sync\grad-planner-storage.json`；桌面（IPC）与平板（HTTP）读写同一文件
- **写入保护**：桌面端 300ms 节流合并写入、平板端 500ms 节流合并 PUT、全部原子写（临时文件 + rename），崩溃不损坏数据
- **同步刷新**：平板写入后桌面端按内容哈希判断再刷新，避免无意义整页重载
- **安全**：contextIsolation + 窄接口 preload；X 密钥 safeStorage 加密；局域网 token 鉴权且不入日志

无账号、无注册、无云端收集；所有数据保存在本机；提醒、备份、同步均为本地/局域网实现。

## 二、耦合分析

### 2.1 已有联动（含本轮新增）

```
文献 ──转待办/转日程──▶ 待办/日历（自动关联阅读进度）
里程碑 ──关联项目──▶ 项目 ──进度自动计算──▶ 任务完成情况
待办到期日 ──自动显示──▶ 日历（📌，点击跳转）      ← 本轮新增
里程碑 ──剩余天数倒计时──▶ 里程碑卡片              ← 本轮新增
资讯 ──存为待办/存为笔记──▶ 待办/笔记               ← 本轮新增
翻译 ──存为笔记（双语对照）──▶ 笔记                 ← 本轮新增
番茄钟 ──关联任务──▶ 待办；番茄记录 ──▶ 统计页
生日 ──农历换算──▶ 日历提醒
习惯/番茄/任务 ──▶ 统计页
全局搜索 ──▶ 跨所有模块
局域网同步 ──▶ 桌面/平板同一份数据（设置页可管理令牌）  ← 本轮新增
```

### 2.2 遗留耦合问题

1. **单一大 store（架构级）**：全部模块共享一个 `state` 对象、存成一个 JSON 文件。已通过"桌面 300ms / 平板 500ms 写入节流 + 原子写"缓解了性能与安全，但模块间边界仍未拆分（需要源码级重构 + 迁移机制，属高投入项）。
2. **提醒覆盖不全**：提醒只覆盖日历事件和生日；任务的截止提醒、习惯的打卡提醒缺失。⬜
3. **统计口径分散**：专注时长、任务完成、习惯打卡分区块展示，缺统一"今日概览"。⬜

## 六、遗留风险提示

1. **局域网明文 HTTP**：token 与数据在同网段明文传输，可被嗅探。个人局域网可接受；介意者建议后续加 HTTPS。
2. **双端并发写无冲突解决**：桌面/平板同时编辑 = 最后写入者覆盖。个人工具可接受。
3. **黄历功能过重**：显著增大 bundle，与主线弱相关，建议评估折叠为可选。
